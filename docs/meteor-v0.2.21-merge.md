# 流星 API 与 Sub2API v0.2.21 合并

官方版本：[v0.2.21](https://github.com/Wei-Shaw/sub2api/releases/tag/v0.2.21)，提交 `10ba8f9b4dc2e6023d4a9879ab77b21841babd10`。
流星基线：`cb4fb8d611f806a968a9aeeb211ab599d1179371`，包含模型实测的上游记录、删除和重测管理。

## 采用官方实现

- OpenAI 30 分钟与 12 小时缓存写入的用量、价卡、数据库记录和展示。已有通用缓存写入价格按官方兼容规则继续生效。
- Codex Desktop 页面上下文处理、元数据事件不提前提交响应、原生生图错误状态，以及函数调用的密封参数和 namespace 保留。
- Responses 工具回合会话稳定、WebSocket 后续轮次限流关闭策略、搜索激活、TTFT 与管理员设置一致。
- 上游过载的模型级冷却、兼容接口的账号自定义错误策略、加载账号失败时的并发槽位释放。
- 刷新令牌原子消费，防止并发轮换重复使用。
- API Key 用量索引与列表分步加载、账号刷新保留现有行、设置页吸附保存按钮。
- EasyPay 实例退款成功码可选 0/1；默认值和现有支付实例配置不变。充值倍率六位小数与本站阶梯费率同时保留。
- Claude Fable / Mythos 5.2 目录、映射与兜底价格、价格目录同步修复及其他官方更新。
- 原有零分配测试使用官方的子进程隔离，保留严格零分配断言。

## 保留流星定制

本次官方没有与以下功能等价的替代接口：

- FZY 视频动态价格快照、实际折后价加价 15%、个人历史费用参考、最高 5 元预扣与完成补差。
- 流星创作台入口、Canvas 访问及现有创作流程、MCP 图片/视频桥接和有期限的媒体缓存。
- 已验证渠道与模型的 GIF 能力及调度缓存。
- 可用性测试、鹈鹕和糖果题、两小时定时、24 小时结果保留、后台上游渠道和结果管理。
- 注册开放时段、充值阶梯费率、经营监控、品牌和导航。

FZY 结算仍进入独立的 `FZYVideoBill` 分支，不改用通用缓存 TTL 定价。现有请求体内存预算显式配置为 512 MiB，新版自动预算仅作用于未配置实例。

## 合并和迁移

唯一文本冲突位于充值页面 import：同时保留 `RechargeFeeTier` 与官方 `formatBalanceRechargeMultiplier`。

新增官方迁移：

- `249_add_usage_logs_api_key_cost_index_notx.sql`
- `250_openai_cache_write_ttl.sql`

迁移程序以完整文件名和校验值判断执行状态，故与现有相同数字前缀的自定义迁移并存；不重命名或修改已经应用的迁移。249 并发创建覆盖索引，首次上线应给索引创建预留足够时间。

官方 tag 内 VERSION 文件仍为 0.2.20，本次明确更新为 0.2.21，供流星 GitHub 镜像构建显示正确版本。

## 验证约定

本地及 GitHub 检查覆盖官方改动、定制计费/认证/支付、模型实测和前端关键流程；数据库迁移由 GitHub PostgreSQL 集成环境验证。验证不创建付费模型任务，不修改客户余额。构建通过与生产部署分别记录。
