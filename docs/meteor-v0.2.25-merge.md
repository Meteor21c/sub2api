# 流星 API 与 Sub2API v0.2.25 合并

- 官方版本：[v0.2.25](https://github.com/Wei-Shaw/sub2api/releases/tag/v0.2.25)（`348997267d756eab5729bb6b78a275a15d18796a`），完整合入 v0.2.23–v0.2.25。
- 流星基线：生产构建 `10b4eef62ed9473cb0f4b561555e46e163dbb813`，包含已部署的 MeteorAgent 登录。版本文件从 tag 中的 0.2.24 显式修正为 0.2.25。

## 采用官方实现

- GPT-6.2 模型识别、长上下文及 Ultra Fast 官方报价与渠道级覆盖继续使用官方实现；经营监控的上游成本口径与客户计费倍率是不同字段，本次不改经营监控计算。
- 保留官方模型字段校验、Codex Research 拒绝分类、Compact 流式重试及 OpenAI 透传结构化错误。错误字段保留不意味着上游一定能解开历史工具结果。
- 接入官方账号请求头变量和上游分组名称/备注同步；不替生产配置启用身份请求头、自动同步或新价格覆盖。
- Claude 和 Bedrock 连通性测试复用官方温度参数兼容规则，同时保留自定义提示词、默认 hello 和测试输出预算。

## 保留流星定制

- Grok 媒体转发采用官方带请求上下文的头覆写，并继续在其后绑定盈合内部身份。输入无效时，在返回 HTTP 400 前归还已冻结的额度。
- 保留盈合独立结算、素材队列、历史估价、预扣上限、创作台、媒体及 MCP 桥接、模型测试、经营监控、注册时段、品牌和充值 10–500 元限制。未发布的 MCP 查图和经营监控改动不混入本次。
- 新增官方迁移 `252_channel_pricing_ultrafast_multiplier.sql`；与现有不同全名的迁移共存，原迁移不改校验值。

发布时由 GitHub 构建临时不可变镜像，备份后只替换主站 Sub2API 容器。验证现有功能和新迁移，不创建付费生成或支付订单。
