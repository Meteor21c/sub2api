# 流星 API 与 Sub2API v0.2.22 合并

官方版本：[v0.2.22](https://github.com/Wei-Shaw/sub2api/releases/tag/v0.2.22)，提交 `b0fa9f3e6eeab1968a53e1289b69daa4bb40ca2b`。
流星基线：`7201635ef7613e7a334f6a88bb2988cb971ffe4f`，包含已经恢复的充值 10～500 限制。
共同基线：官方 v0.2.21 `10ba8f9b4dc2e6023d4a9879ab77b21841babd10`。

## 采用官方实现

- 普通用量扣费采用官方按用户合并的结算通道及批量数据库事务，并保留官方结算完成后的独立缓存同步超时。
- 调度快照与回源使用官方并发合并、预解析复用和 last-used 短缓存；保留已配置的图片输出格式能力。
- 分组日汇总重建及用量清理采用官方非阻塞流程，避免汇总期间阻塞用量写入。
- 采用官方 TCP keepalive、Linux TCP_USER_TIMEOUT 与平台兼容处理，缩短失效连接等待；保留现有指定账号 HTTP/1.1 的配置。
- Codex additional_tools、分叉会话缓存键、Chat/Responses/Anthropic 工具与结构化输出转换、SSE keepalive 和错误切换等协议修复。
- Gemini 并行工具、结构化输出、实际缓存用量、Carbon/Hydrogen 定价，及 Vertex us/eu 端点。官方的端点 1.1 倍仅作用于默认价；管理员分组/渠道自定义价格不叠加。
- 官方强制 Ultra Fast 分组、透传账号按模型过滤、分组倍率/RPM 同步、额度刷新和监控显示修复。
- 官方支付宝退款重试幂等及 HTML 设置注入的 no-store/CSP nonce 修复。保留流星缓存失效与并发渲染之间的保护。
- 其余 v0.2.21 到 v0.2.22 的官方变更完整合入，包括构建工具链 Go 1.27.4。

## 保留定制与兼容处理

本版没有能够等价替换下列产品功能的官方接口：

- 盈合视频的 key 实际折后价 × 1.15、个人历史价格参考、最高 5 元预扣、完成后补差或失败退还。
- 创作台/Canvas、MCP 图片视频桥接、素材入库队列与有期限的媒体缓存清理。
- 仅对已验证账号和模型启用的 GIF 输出能力。
- 鹈鹕/糖果模型实测、两小时自动测试、24 小时保留、管理员上游记录及删除/重测管理。
- 注册开放时段、阶梯充值费率、经营监控、品牌及导航。

新版依赖注入把原始计费仓库包装为 `UsageBillingLaneCombiner`，直接合并会令盈合专用接口断开。本次新增独立适配文件 `usage_billing_lane_fzy.go`，把视频冻结、绑定、查询、释放、结算、后台对账与历史样本操作转交原始仓库。普通请求继续使用官方批处理；视频结算继续采用任务专用事务，不进入通用 `Apply` 再扣一次。

账号成本保留视频上游实际成本基数，接入官方新增端点倍率参数时显式使用 1，不对冻结的视频价快照叠加 Vertex 倍率。现有视频预扣后的缓存失效逻辑继续保留。

充值相关实现与生产基线逐字节一致：站点限制作用于原始输入金额，渠道限制作用于折扣后支付额，1000/2000/5000 快捷档位继续隐藏。已配置的 512 MiB 请求体内存预算保持有效。

## 合并与数据库迁移

- `cmd/server/wire_gen.go`：保留模型实测及经营监控生命周期，同时加入官方结算通道生命周期；重新生成 Wire。
- `internal/service/openai_gateway_usage.go`：保留盈合成本基数，同时接入官方账号成本计算新增参数。

新增官方迁移：

- `251_group_force_openai_ultrafast.sql`
- `251_group_usage_rollup_nonblocking_build.sql`

迁移程序以完整文件名及校验值识别迁移，与同数字前缀的流星迁移并存。312 个已有 SQL 迁移文件保持原内容，不重命名、不改校验值。

官方 tag 中 VERSION 仍为 0.2.21，本次明确更新为 0.2.22。
