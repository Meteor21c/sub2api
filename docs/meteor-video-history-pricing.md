# 视频历史参考与预扣

## 规则

- 仅使用当前用户最近 90 天、最多 200 条已结算记录；相同模型、计价场景、分辨率及帧率，已记录的画面比例与音频参数也必须相符。
- Token 模型至少有 3 条可用记录时，将每秒输出 Token 按当前售价与当前请求时长重新换算；中位数为参考值，25%–75% 分位数为参考区间。
- 预扣采用区间上沿并向上取整到分，最低 0.01 元，最高 5 元。参考价不截断；历史金额仍展示实际结算值，不随当前价格改写。
- 没有足够记录时默认预扣：Seedance 2.0/2.5 为 5 元，Mini 与腾讯增强为 1 元，其他 Token 模型为 2 元。这些数值仅是预扣预算，不是总价估计。
- 按秒模型继续按当前参数计算参考费用（含 H3 参考素材费用），实际预扣也封顶 5 元。最终结算仍使用创建时冻结的价格和上游真实用量，多退少补，失败退款。
- 实际输出时长单独记录；旧记录只有请求参数时长时明确标注。零时长、缺少 Token，以及自动时长且无实际时长的记录不参与估算。

## 数据边界

`GET /v1/videos/pricing?model=...&history=true` 只返回已认证 API key 所属用户最近 20 条记录；不接受外部用户 ID 作为查询身份，不依赖调度账号当前可用性。

响应仅包含时间、规格、白名单参数、用量、费用，不包含提示词、素材、上游地址、任务 ID、用户 ID、密钥或内部价格快照。查询有用户条件、90 天边界、数量上限及专用索引；不新增内容副本，也不改变媒体缓存清理规则。

## 发布与验收

1. GitHub 构建主站和创作台，保留旧镜像及数据库/编排备份。
2. 先更新主站并应用迁移 `251_fzy_video_cost_history.sql`，再更新创作台。迁移只新增字段与索引，不改写历史账单。
3. 使用本人测试账户只读查看报价、费用历史和账号隔离；检查同参数预览与提交共用同一预扣策略，不发起无关付费任务。
4. 确认主站、创作台及无关服务健康。新字段允许旧版本回滚运行；不撤销已应用迁移。

参考费用仅用于提示，不要求余额覆盖参考价；没有参考价也可提交。提交时仅要求可用余额覆盖本次预扣额，预扣最高 5 元。最终按实际费用多退少补，余额不足时仍可能补扣为负数。
